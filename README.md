# Clukva (Special for Mizuki)

[![](https://jitpack.io/v/Rediska4445/clukva.svg)](https://jitpack.io/#Rediska4445/clukva)

Special utility toolkit for Java

* Type-safe collections
* HTTP client
* Advanced logging
* Concurrency

## Dependencies

- `java.base` — core functionality
- `java.logging` — optional JUL bridge

## Integration

Add to module path or classpath:
```xml
<!-- Maven -->
<dependency>
    <groupId>com.github.Rediska4445</groupId>
    <artifactId>clukva</artifactId>
    <version>Tag</version>
</dependency>
```
